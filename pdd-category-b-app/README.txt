ПДД РФ — приложение для категории B

Содержимое:
- index.html — учебник
- manifest.webmanifest — параметры установки на главный экран
- sw.js — офлайн-кэш приложения
- icon-192.png и icon-512.png — иконки

ВАЖНО:
Чтобы установить приложение на iPhone как отдельную иконку и включить офлайн-режим,
сайт нужно один раз разместить по HTTPS. Открытие HTML-файла из приложения «Файлы»
не позволяет корректно установить PWA и зарегистрировать Service Worker.

После публикации:
1. Откройте адрес сайта в Safari на iPhone.
2. Нажмите «Поделиться».
3. Выберите «На экран Домой».
4. Включите «Открывать как веб-приложение», если такой переключатель показан.
5. Нажмите «Добавить».
6. Первый раз откройте приложение при подключённом интернете, дождитесь загрузки,
   затем оно будет доступно офлайн.

Файлы готовы к публикации на статическом HTTPS-хостинге (например, GitHub Pages).
